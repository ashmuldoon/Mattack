# Mattack
Simple multiplayer game for versing friends with your maths skills.

Planned gameplay loop:
Start with an initial set of equations and math problems to solve to deal damage to opponent
As the game goes on, choose cards that give you more complex or specific math problems to eventually defeat your opponent.
